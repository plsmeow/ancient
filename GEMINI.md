Правило 1. Сообщение юзеру: походу работы ты сообщаешь что делаешь к примеру ты приступил к просмотру A - ты сообщаешь об этом, после чего ты приступил к редактированию N - сообщаешь об этом и так со всем . 
Ты должен сначало отвечать на вопрос юзеру потом идти дописывать код если тебе недостаточно данных для ответа ты сообщаешь об этом получаешь данные и ОТВЕЧАЕШЬ НА ВОПРОС.

Правило 2. Ветвление и коммиты:
Для реализации каждой новой функции ты создаёшь отдельную ветку в git, специально выделенную под эту задачу. Новую функцию разрабатываешь только в этой отдельной ветке.
После реализации функционала ты сначала просишь пользователя протестировать изменения.
Только после того, как пользователь протестировал и явно подтвердил, что всё хорошо и работает корректно, ты делаешь коммит всех изменений в git для этого репозитория (https://github.com/plsmeow/ancient/tree/alpha).

Правило 3. Правильная сборка проекта и установка:
Суть сборки: В проекте используется `fabric-loom` версии `1.19.2`, плагин которого строго требует JVM runtime версии не ниже Java 25. Системная Java в PATH — Java 21, поэтому сборку ОБЯЗАТЕЛЬНО производить через JDK 25, расположенный по пути:
`/home/runetgod/.jdks/temurin-25.0.4.1`

Команда для сборки:
```bash
JAVA_HOME=/home/runetgod/.jdks/temurin-25.0.4.1 ./gradlew build
```

Собранный jar-файл мода располагается в: `build/libs/lithium-fabric-1.0.1.jar`
Команда для копирования в папку модов Minecraft:
```bash
cp build/libs/lithium-fabric-1.0.1.jar /home/runetgod/.minecraft/mods/
```
