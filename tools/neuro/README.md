# Neuro Rotation Training

Обучение моделей для AI-rotation в Minecraft.

## Требования

```bash
python -m pip install -r requirements.txt
```

## Использование

### 1. Запись датасета

В игре: включите модуль **Ai Record** (категория MISC).

- **Режим**: Слизни (автоматическая генерация целей) или KillAura (боевая запись).

Метки — только человеческие движения мыши (источник «Ротация» удалён: обучение
на выводе детерминированной ротации вырождало модель).

При выключении модуля датасет сохраняется автоматически как `.options/ai/datasets/dsMMdd_HHmm.jsonl`.

### 1b. Дамп чужих ротаций

Можно записывать ротации других игроков (например, сильных дуэлянтов):

```
.ai dump start ник1|ник2     — начать запись (1+ ников через |)
.ai dump stop                — остановить и сохранить dumpMMdd_HHmm.jsonl
```

Игроки должны находиться в прогруженном мире. Фичи собираются от наблюдаемого
игрока (его скорость, его цель — ближайшая сущность в 6 блоках), метка —
фактическая дельта его поворота между тиками. Источник — HUMAN.

### 2. Обучение

```bash
python tools/neuro/train.py --dataset ds0807_1430.jsonl --out rotation-v1 --epochs 100 --arch mlp
```

**Аргументы:**
- `--dataset` — путь к `.jsonl` датасету
- `--out` — имя модели (создаст `.options/ai/models/<name>/`)
- `--epochs` — число эпох (default 100)
- `--arch` — архитектура: `mlp` (плоское окно) или `gru` (рекуррентная)
- `--base` — базовая модель для fine-tuning (`.ai improve`)
- `--lr` — learning rate (default 1e-3)
- `--batch-size` — размер батча (default 32)
- `--patience` — early stopping patience (default 10; `0` — выключен, обучение идёт все эпохи до конца). Из игры (`.ai train` / `.ai improve`) всегда запускается с `--patience 0` — сколько эпох указали, столько и обучается
- `--quality` — фильтр качества (default `CLEAN`)

### 3. Загрузка в игре

```
.ai load rotation-v1
```

### 4. Улучшение модели

После новых записей:

```bash
python tools/neuro/train.py \
  --dataset .options/ai/datasets/ds0807_1530.jsonl \
  --out rotation-v1-improved \
  --base rotation-v1 \
  --epochs 50
```

Или через игру:

```
.ai improve rotation-v1 ds0807_1530 50
```

## Архитектура

### MLP (рекомендовано)

Плоское окно `seq_len × features` → MLP. Проще, быстрее, хорошо работает на коротких окнах.

### GRU

Рекуррентная сеть. Медленнее, может давать лучшие результаты на сложных траекториях.

## Метрики

- **val_loss** — L1 loss на валидационном split
- **yaw_mae** / **pitch_mae** — средняя абсолютная ошибка в градусах
- Golden test проверяет, что PyTorch и ONNX Runtime дают одинаковый выход (до 1e-5)

## Формат датасета

Одна строка JSON на сэмпл:

```json
{"f": [33 floats], "y": [2 floats], "q": "CLEAN", "s": "HUMAN", "t": 42}
```

- `f` — фичи (33 × 8 временных шагов)
- `y` — метка [deltaYaw, deltaPitch]
- `q` — качество (CLEAN / TRANSITION / TARGET_SWITCH / OCCLUDED / INVALID)
- `s` — источник (всегда HUMAN; другие источники при обучении отбрасываются)
- `t` — номер тика

Мета в `.meta.json` содержит `schemaVersion`, статистику и баланс.

## Troubleshooting

**"schemaVersion < 2"** — датасет записан старой версией. Перезапишите через Ai Record.

**"Источник датасета: ROTATION/MIXED"** — обучение только на человеческих записях. Перезапишите через Ai Record или `.ai dump`.

**"Early stopping на эпохе N"** — это не ошибка, а штатная защита от переобучения: val-loss не улучшался `--patience` эпох подряд, восстановлены веса лучшей эпохи. Срабатывает только при ручном запуске (default `--patience 10`); из игры обучение всегда идёт до конца (`--patience 0`). Для ручного запуска без остановки: `--patience 0`.

**"Не удалось построить непрерывного окна"** — запись слишком короткая или разорвана. Записывайте длинные непрерывные бои (минимум 100+ тиков).

**Golden test failed** — сообщите разработчику, это критический баг.
